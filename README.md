# Focus Pomodoro

업무 중 집중 시간을 관리하기 위한 개인용 뽀모도로 앱 준비 저장소입니다.

## 문제와 사용 환경

- Galaxy A90(Android 12)을 집중 전용 폰으로 활용합니다.
- 업무 중 타이머를 간단하게 조작하고 집중 구간이 끝났음을 알아야 합니다.
- 인터넷 연결 없이 핵심 기능을 사용할 수 있어야 합니다.

## 현재 상태

React Native로 진행하는 방향을 선택했습니다. TypeScript와 Expo 조합은 제안 상태이며 아직 확정하지 않았습니다. 상세 기능과 구조는 논의 중입니다. 이 저장소는 문서 준비 단계입니다. 프레임워크 프로젝트 생성, 패키지 설치, 앱 구현, 배포는 후속 결정 이후 진행합니다. 초기 준비 문서만 공개 저장소로 관리합니다.

## 최소 기능 제안 — 미확정

| 기능 | 제안 동작 | 결정할 사항 |
| --- | --- | --- |
| 시작 | 선택한 집중 시간의 카운트다운 시작 | 기본 시간과 사용자 변경 범위 |
| 일시정지 | 남은 시간을 보존하고 재개 가능 | 화면 잠금 중 동작 |
| 초기화 | 진행 상태를 초기 시간으로 되돌림 | 실행 중 확인 절차 |
| 종료 알림 | 집중 구간 완료를 사용자에게 알림 | 소리·진동·시스템 알림, 무음 모드 동작 |

휴식 구간, 반복 횟수, 기록·통계, 계정 및 동기화는 도입 여부를 별도로 결정합니다.

## 오프라인 우선 원칙

- 시작·일시정지·초기화·종료 알림은 네트워크에 의존하지 않도록 설계합니다.
- 필요한 설정과 타이머 상태는 기기 내부에 보관하는 방향을 우선 검토합니다.
- 로그인이나 서버를 핵심 사용 흐름의 전제 조건으로 두지 않습니다.
- 화면 잠금, 백그라운드 전환, 프로세스 종료 및 절전 모드에서의 동작은 Galaxy A90 실기기로 검증합니다. 재실행 시 상태 복구 범위는 아직 미정입니다.
