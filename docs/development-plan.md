# 개발 계획

React Native로 진행하는 방향은 선택했습니다. TypeScript와 Expo는 제안 상태이며, 상세 기능과 구조는 확정 전입니다. 후속 결정을 기록한 다음 구현 범위를 좁힙니다.

1. **사용 규칙 결정**: 집중 시간, 휴식 포함 여부, 반복 여부, 일시정지·초기화 규칙, 알림 방식과 화면 잠금 중 요구사항을 정합니다.
2. **개발 도구 결정**: 선택한 React Native 방향에서 TypeScript와 Expo 제안을 검토합니다. 오프라인 사용, Android 12 백그라운드 타이머와 알림, APK 설치 및 유지보수 비용을 기준으로 확인합니다.
3. **핵심 동작 설계**: 대기·실행·일시정지·완료 상태, 남은 시간 계산, 로컬 저장과 재실행 시 복구 범위를 정합니다. 타이머 정확성은 화면 갱신 주기와 별개로 검토합니다.
4. **최소 구현**: 기술과 범위 확정 후 프로젝트 생성 및 필요한 의존성 설치를 진행합니다. 시작·일시정지·재개·초기화·종료 알림을 우선 구현합니다.
5. **실기기 검증**: Galaxy A90(Android 12)에서 비행기 모드, 화면 잠금, 백그라운드, 절전 모드, 알림 설정 변경을 확인합니다. 프로세스 종료 후 동작은 결정한 요구사항에 맞춰 검증합니다.
6. **개인 사용 준비**: 설치 방법과 알려진 제한을 기록하고 업무 중 사용하면서 불편을 확인합니다. 앱 배포는 별도 요청이 있을 때 진행합니다.

## 첫 결정 목록

- React Native 기반의 TypeScript·Expo 제안 채택 여부
- 집중 시간과 휴식·반복 기능의 초기 범위
- 화면 잠금·백그라운드·프로세스 종료 시 기대 동작
- 종료 알림 방식과 무음·방해 금지 모드에서의 기대 동작

결정은 `docs/decisions/000-template.md`를 복사해 번호와 주제를 붙인 문서로 기록합니다.
